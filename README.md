## Description du projet
Ce projet implémente un système universitaire simple en utilisant la programmation orientée objet en Java.

## Classes implémentées
- `Personne` - Classe de base pour les personnes
- `Etudiant` - Classe des étudiants (hérite de Personne)
- `Professeur` - Classe des professeurs (hérite de Personne)
- `Cours` - Classe des cours universitaires
- `Main` - Programme principal de démonstration

## Comment exécuter
```bash
javac *.java
java Main
